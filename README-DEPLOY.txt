ЛЕВ ТОЛСТОЙ. НАСЛЕДИЕ БУДУЩЕГО — демоверсия для GitHub Pages (v0.6.2)

Это статический HTML/CSS/JS-сайт. WordPress и PHP не нужны.
В этой сборке использованы последние исправления из WordPress-плагина v0.6.2:
— обработанное изображение после сканирования на этапе B;
— увеличение фрагмента рукописи на этапе D;
— уточнена загрузка трёх фотографий внутри интерактивных окон.

ПУБЛИКАЦИЯ
1. Распаковать ZIP.
2. Создать пустой публичный репозиторий GitHub, например tolstoy-museum.
3. Добавить в корень репозитория СОДЕРЖИМОЕ распакованной папки:
   index.html, css/, js/, assets/, .nojekyll, README-DEPLOY.txt и ASSETS_AND_RIGHTS.md.
   Важно: не загружать один ZIP вместо файлов, не переносить их в дополнительную папку.
4. В GitHub: Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save.
5. Адрес сайта: https://<username>.github.io/tolstoy-museum/
6. В меню Actions / Pages проверить статус, если сайт пока не открылся.

ПРАВА
Это технически готовый демонстрационный комплект, но наличие изображений в архиве
НЕ подтверждает разрешение на их публичную публикацию. До размещения в открытом
репозитории и на публичном сайте убедитесь в наличии прав на все музейные
изображения, рукопись и прочие материалы. См. ASSETS_AND_RIGHTS.md.
Для ограниченного по доступу показа GitHub Pages на обычном тарифе не подходит.
